# studyRag — 仕様駆動開発で学ぶRAG

社内マニュアルを検索し、根拠となる文書名を添えて回答する小さな学習用アプリです。外部API・APIキー・追加ライブラリを使わず、ローカルで動作します。

## 学習できること

- 文書の読み込みとチャンク化
- BM25風の語句検索と日本語文字n-gram
- 関連度が低い質問への回答保留
- 回答と引用元をセットで返す設計
- 仕様 → 計画 → タスク → 実装 → テストのスペック駆動開発

現段階ではLLMによる文章生成を行わず、検索結果の抜粋を回答として返します。これは検索・根拠提示・棄却の基準を独立に評価するためのベースラインです。後続学習でLLMを接続する場合も、出典表示と回答保留は維持します。

## 起動

Python 3.11以上を用意し、プロジェクトフォルダーで実行します。

```powershell
python -m app.rag_app
```

ブラウザーで <http://127.0.0.1:8000> を開いてください。ポートを変える場合は `PORT` 環境変数を指定します。

## テスト

```powershell
python -m unittest discover -s tests -v
```

## API

`POST /api/query` に `{"question":"休暇の申請方法は？"}` を送ります。回答には根拠の引用元と関連度を含みます。`GET /health` は稼働確認用です。

## Copilotで進める手順

このリポジトリには、GitHub Spec Kitの仕様・計画・タスクに相当する成果物を `specs/001-grounded-search/` に置いています。Spec Kit公式の現在の流れは、constitution → specify → clarify → plan → checklist → tasks → analyze → implement → converge です。Copilot Chatで各 `/speckit-*` スキルを一つずつ呼び、成果物をレビューしてから次に進みます。

この雛形はCLIテンプレートを使わずに構成し、仕様・設計・タスクを先に整えています。次の学習段階では、公式CLIでSpec Kitを初期化し、Copilotの各スキルを使って仕様と実装の整合を確認できます。
