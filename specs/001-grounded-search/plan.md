# 実装計画

## 技術方針

- Python 3.11+ と標準ライブラリのみを使い、初回実行の外部依存をなくす。
- `ThreadingHTTPServer` で小さなブラウザー画面とJSON APIを提供する。
- Markdownを空行区切りでチャンク化し、文字数上限500を守る。
- BM25風の逆文書頻度と日本語文字bigramを使うローカル検索を実装する。
- 生成AIを接続せず、検索された抜粋を回答として出典付きで返す。
- 最大要求サイズを16 KiBに制限し、入力型を検証する。

## 構成

```text
app/rag_app.py       チャンク化、検索、回答、HTTPエンドポイント
data/*.md            架空の検索対象文書
tests/test_rag.py    振る舞いの自動テスト
specs/               SDD成果物
```

## 評価方針

既知の質問で期待文書の順位と出典を確認する。文書にない質問では保留する。後続段階で固定評価セット、Recall@k、チャンクサイズ比較、ベクトル検索との比較を追加する。
